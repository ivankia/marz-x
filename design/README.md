# Handoff: Сайт VPN-сервиса «PPN»

## Overview
Маркетинговый сайт + личный кабинет для VPN-сервиса **PPN**. Минималистичный
дизайн в светлых тонах с одним акцентным цветом. Пять разделов:
**Главная, Тарифы, Личный кабинет, Информация, Контакты.**
Эстетика: премиальная и спокойная — много воздуха, тонкая типографика,
нейтральный гротеск, без визуального шума.

## About the Design Files
Файл `PPN.dc.html` в этом пакете — **дизайн-референс, сделанный в HTML**. Это
прототип, демонстрирующий желаемый внешний вид и поведение, **а не продакшен-код
для копирования один в один**. Задача — **воссоздать этот дизайн в целевом
кодовом окружении** (заказчик упоминал **React + React-Bootstrap**), используя
принятые в проекте паттерны и компоненты. Если окружения ещё нет — создать новый
React-проект и реализовать дизайн там.

> Технические замечания по референсу: файл написан в формате внутреннего
> прототип-движка (теги `<x-dc>`, `<sc-if>`, `<sc-for>`, плейсхолдеры `{{ }}`).
> Это **не нужно** переносить в продакшен — это лишь способ, которым собран
> прототип. Ориентируйтесь на разметку, стили, тексты и описанное ниже поведение.
> Чтобы просто посмотреть дизайн в браузере, откройте `PPN.dc.html` напрямую.

## Fidelity
**High-fidelity (hi-fi).** Финальные цвета, типографика, отступы и интерактив.
Воссоздавайте интерфейс пиксель-в-пиксель средствами вашего стека. React-Bootstrap
покрывает структуру (Navbar, Container, Row/Col, Card, Button, Form, ListGroup,
Nav/Tab), но **точные значения цветов, радиусов и шрифт задавайте кастомным CSS /
SCSS-темой** — дефолтная тема Bootstrap по стилю не совпадает.

## Design Tokens

### Цвета
Заданы как CSS custom properties (рекомендуется так же определить в `:root` или
теме). В прототипе используется цветовая модель **oklch** и функция **color-mix**
(поддерживаются всеми актуальными браузерами). Рядом даны приблизительные HEX.

| Токен | Значение (oklch) | ≈ HEX | Назначение |
|---|---|---|---|
| `--bg` | `oklch(0.99 0.004 285)` | `#fbfbfc` | Фон страницы (тёплый светлый) |
| `--surface` | `#ffffff` | `#ffffff` | Карточки, шапка, футер |
| `--line` | `oklch(0.925 0.006 285)` | `#e9e8ed` | Границы, разделители |
| `--line-strong` | `oklch(0.87 0.008 285)` | `#d6d4dc` | Границы инпутов/кнопок |
| `--text` | `oklch(0.245 0.013 285)` | `#27262d` | Основной текст |
| `--muted` | `oklch(0.52 0.012 285)` | `#6f6d78` | Вторичный текст |
| `--faint` | `oklch(0.66 0.01 285)` | `#9b99a3` | Подписи, мета |
| `--accent` | по умолчанию `#a3b234` * | `#a3b234` | Акцент: кнопки, ссылки, выделения |
| `--accent-d` | `color-mix(in oklab, var(--accent), black 18%)` | — | Акцент при ховере |
| `--accent-soft` | `color-mix(in oklab, var(--accent), white 90%)` | — | Светлая подложка акцента |
| Успех (онлайн/оплачено) | `oklch(0.66 0.15 152)` | `#3ea36a` | Статус «защищено», бейдж «оплачено» |
| Пинг средний | `oklch(0.66 0.13 70)` | — | Пинг 40–99 мс |
| Опасность (ховер «выйти») | `oklch(0.55 0.16 25)` | — | Удаление устройства |

\* **Про акцент.** Базовая палитра проектировалась под фиолетовый `#6d4dd6`.
Заказчик в твиках переключил дефолт на оливково-зелёный **`#a3b234`** — это
актуальный цвет на момент хендоффа. Сделайте акцент **одной темизируемой
переменной**, чтобы цвет менялся в одном месте. Курируемый набор опций из
прототипа: `#6d4dd6` (фиолет), `#2f6df6` (синий), `#16a36a` (зелёный),
`#e8643a` (оранжевый), `#111111` (графит).

### Типографика
- Семейство: **Hanken Grotesk** (Google Fonts), веса 300, 400, 500, 600, 700.
  Фолбэк: `system-ui, sans-serif`.
- H1 (hero): `clamp(42px, 5.6vw, 70px)`, weight 400, letter-spacing −0.028em, line-height 1.04.
- H1 (страницы): `clamp(36px, 4.4vw, 58px)`, weight 400, letter-spacing −0.028em.
- H2 секций: `clamp(30px, 3.6vw, 42px)`, weight 400, letter-spacing −0.02em.
- H1 кабинета: 28px, weight 500.
- H3 карточек: 16–20px, weight 500–600.
- Body крупный (лиды): 18–19px, weight 300, line-height 1.6.
- Body: 14.5–15px, line-height 1.6.
- Eyebrow (надзаголовок): 12.5px, weight 600, uppercase, letter-spacing 0.16em, цвет `--accent`.
- Подписи/мета: 11–13px, цвет `--faint`, часто uppercase + letter-spacing 0.1–0.12em.
- Цифры (трафик, суммы): `font-variant-numeric: tabular-nums`.

### Радиусы
- `--radius`: **16px** (дефолт, темизируется: rounded 16 / soft 10 / sharp 4).
- Кнопки: `calc(var(--radius) − 5px)` ≈ 11px.
- Мелкие карточки/инпуты: 10–14px.
- Бейджи/пилюли: 999px.

### Отступы
- `--sec`: вертикальный отступ секций **120px** (дефолт «airy»; «standard» = 84px).
- Контейнер: `max-width: 1140px; padding: 0 32px;` (кабинет/инфо ‒ свои max-width: инфо 820px).
- Высота шапки: 74px.
- Gap сеток: 18–20px (карточки), 36–64px (крупные колонки).

### Тени
- Карточка-герой: `0 1px 2px rgba(30,20,60,0.04), 0 24px 60px -34px rgba(50,35,110,0.30)`.
- Карточка тарифа (популярный): `0 30px 70px -44px rgba(50,35,110,0.4)`.
- Кнопка-лого (мягкое свечение): `0 4px 14px -4px` от акцента.

- **Лого:** скруглённый квадрат 30×30 с акцентным фоном + белый ромб (квадрат, повёрнутый
  на 45°) 11×11 внутри. Рядом текст `ppn`, 21px, weight 600, letter-spacing −0.04em.
- **Навигация:** Главная / Тарифы / Кабинет / Информация / Контакты. Активный пункт — цвет

  ведёт в Личный кабинет. Ховер → `--accent-d`.

- **Вариант A — центрированный:** eyebrow, крупный H1 (max 15ch), лид-параграф (max 52ch),

- **Вариант B — сплит:** слева текст + кнопки + 3 инлайн-метрики (60+ / 10 / 0);

- **Вариант C — редакторский:** очень крупный H1 (weight 300, до 88px) со словом

- **Сайдбар:** карточка профиля (аватар-инициалы «АК», имя, тариф) + вертикальное меню

- **Вкладка «Устройства»:** список устройств (иконка, имя, ОС + последняя активность,

## Interactions & Behavior
- **Навигация:** клик по пунктам шапки/футера и CTA-кнопкам меняет активную страницу
  (в продакшене — роуты).
- **Переключатель вариантов главной:** только для выбора дизайна; в продакшен идёт один вариант.
- **Кабинет → toggle подключения:** меняет статус «Защищено ⇄ Не подключено», цвет индикатора
  (зелёный/серый), текст IP и вид кнопки (заливка/контур).
- **Кабинет → выбор сервера:** клик по строке меняет текущий сервер; влияет на карточку
  подключения в «Обзоре».
- **Кабинет → удаление устройства:** убирает строку из списка.
- **FAQ:** аккордеон — раскрыт максимум один пункт; повторный клик закрывает.
- **Форма контактов:** submit (с `preventDefault`) → экран успеха.
- **Ховеры:** кнопки темнеют до `--accent-d` или меняют бордюр/цвет на акцент;
  ссылки футера → акцент. Переходы 0.15s.
- **Адаптив:** референс рассчитан на десктоп (≥1140px). Мобильную раскладку нужно
  спроектировать при реализации (колонки → стек, бургер-меню в шапке, сайдбар кабинета
  в выпадающее/верхнее меню). Сетки удобно перевести на `Row`/`Col` с брейкпоинтами.

## State Management
В прототипе один компонент со state:
- `page` — активная страница (→ роутер).
- `homeVariant` — вариант героя (только для прототипа).
- `connected` (bool) — статус VPN.
- `server` (id) — выбранный сервер.
- `dashTab` — активная вкладка кабинета (→ вложенные роуты/табы).
- `faq` — индекс раскрытого вопроса (или null).
- `contactSent` (bool) — форма отправлена.
- `devices` — массив устройств (для удаления).
Данные серверов/тарифов/FAQ/истории платежей — статические в прототипе; в продакшене
тянуть из API (трафик, серверы, подписка, устройства).
